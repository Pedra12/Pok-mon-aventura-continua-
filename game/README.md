# Pokemon Aventura Continua

Projeto principal Android/Godot. Os arquivos GLB originais são copiados pelo workflow de compilação para `game/assets/`; o mapa e os modelos-fonte não são modificados.

O jogo inicial inclui exploração 3D da vila, câmera de terceira pessoa, joystick virtual, rotação por toque, salto e interação com Pokémon próximos. Esta é a primeira base executável; animações de movimento/combate, colisões refinadas por área e revisão visual em dispositivo continuam sendo critérios separados antes de considerar o jogo finalizado.
