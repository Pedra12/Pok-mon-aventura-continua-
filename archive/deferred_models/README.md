# Modelos 3D arquivados

Eevee, Lucario e Mew foram retirados do conjunto ativo porque ainda precisam de rigging e skinning específicos. Os arquivos GLB originais foram preservados aqui, sem alteração. O workflow de validação copia apenas os GLBs da raiz do repositório, portanto estes modelos não entram no projeto ativo nem nas compilações de validação.
